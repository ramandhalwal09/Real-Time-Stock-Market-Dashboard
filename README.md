# Real-Time-Stock-Market-Dashboard
A real-time stock market dashboard built with Streamlit, Python, Pandas, and Plotly. Fetches live financial data via API, tracks key indicators, and visualizes price trends with interactive line and candlestick charts. Perfect for monitoring market movements instantly.

## Features
* **Real-Time Data Fetching:** Pulls instant market prices and financial metrics using backend API requests.
* **Interactive Visualizations:** Toggle between crisp **Line Charts** and detailed **Candlestick Charts** powered by Plotly.
* **Key Financial Indicators:** Instantly displays Current Price, Day High, Day Low, Market Cap, and net daily changes.
* **Custom Ticker Support:** Track popular tech stocks (AAPL, TSLA, NVDA) or type in any custom ticker manually.
* **Historical Data Inspection:** Expandable data view to inspect the underlying Pandas DataFrame structure.

## Technologies Used
* **Python** (Core language)
* **Streamlit** (Web dashboard framework)
* **Pandas** (Data manipulation & analysis)
* **Plotly** (Interactive data visualization)
* **yfinance** (Financial data API client)

## Installation & Setup

Install the required dependencies:

pip install streamlit yfinance pandas plotly

## How to Run

In the terminal of app.py runt this :

streamlit run app.py
